# Lakshita Jaju — Portfolio

Personal portfolio website for **Lakshita Jaju**, a digital marketer and UI/UX designer.

## 🔗 Live Preview

Open `index.html` in any browser to view the site.

## ✨ Features

- **Single-page layout** — no build tools, frameworks or dependencies
- **Dark theme** with lavender accent (`#a78bfa`), charcoal background (`#1e1e1e`), and cream text (`#f5f3ee`)
- **Responsive** — adapts to mobile with a hamburger menu
- **Scroll animations** — elements reveal on scroll, skill bars animate, stat counters count up
- **Respects `prefers-reduced-motion`** — disables all animation for users who opt out
- **Profile photo** in hero and about sections
- **Certificates & Case Studies** section with PDF viewer links
- **Contact form** opens the visitor's default mail client (no backend needed)

## 📌 Sections

| Section | Description |

## 🛠 Tech

- HTML5, CSS3 (custom properties, grid, flexbox, `clamp()`)
- Vanilla JavaScript (IntersectionObserver, requestAnimationFrame)
- Google Fonts: Bricolage Grotesque + Figtree
